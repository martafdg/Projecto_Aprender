# Plano: Redesenho da Comunicação Interna

Propõe uma nova estrutura de comunicação interna para a Quintinha ABC que reduza o ruído, aumente a eficácia e diminua a dependência de WhatsApp ad-hoc.

## Contexto do problema

A comunicação interna atual é quase 100% por WhatsApp, mistura conteúdos de natureza muito diferente (urgente/não urgente, operacional/social, individual/coletivo), e não deixa registo consultável. Informação crítica perde-se. Voluntários não leem. Coordenadores são contactados a todas as horas para abrir o portão.

## O que fazer

### 1. Princípios de design da nova comunicação
Define princípios base:
- **Canal certo para o propósito certo** — cada tipo de mensagem tem um canal definido
- **Assíncrono por defeito** — urgência real é exceção, não regra
- **Registo persistente** — informação operacional deve ser consultável depois
- **Menos grupos, mais clareza** — reduzir fragmentação

### 2. Redesenho dos grupos e canais
Para cada tipo de comunicação, propõe o canal mais adequado:

| Tipo de comunicação | Canal atual | Canal proposto | Justificação |
|---|---|---|---|
| Reporte diário do abrigo | WhatsApp Geral | ? | |
| Pedidos urgentes | WhatsApp Geral | ? | |
| Pedidos de transporte | WhatsApp Geral | ? | |
| Distribuição de tarefas | WhatsApp equipa | ? | |
| Abertura do portão | WhatsApp Alternativo | ? | |
| Parabéns / social | WhatsApp Alternativo | ? | |
| Pedidos não urgentes | Misto | ? | |
| Comunicação entre coordenadores | WhatsApp coordenadores | ? | |
| Email geral do abrigo | Gmail partilhado | ? | |

### 3. Solução para o portão
O portão é um ponto de fricção constante. Propõe soluções:
- Sistema de abertura automática por aproximação (NFC, app)?
- Lista de pessoas com acesso de abertura alargada?
- Horários fixos de abertura?
- Outro?

### 4. Redesenho do reporte diário
O reporte diário não é lido. Por quê? O que poderia substituí-lo ou melhorá-lo?
- Formato mais visual ou resumido?
- Canal diferente?
- Cadência diferente (semanal em vez de diário)?
- Quem realmente precisa do reporte e para quê?

### 5. Plano de transição
- Como migrar da situação atual sem criar disrupção?
- Que ferramentas são necessárias?
- Como comunicar as mudanças?
- Que formação é precisa?

## Output esperado

1. **Nova arquitetura de comunicação** — diagrama com canais, audiências e propósitos
2. **Regras de uso** — 1 página com as regras de "o que vai para onde"
3. **Solução para o portão** — proposta concreta
4. **Template de reporte redesenhado** — novo formato mais eficaz
5. **Plano de transição** — passos concretos com responsáveis e prazos
