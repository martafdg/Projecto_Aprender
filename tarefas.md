## 📬 EMAIL — Sistema de triagem

### T7 — Criar `transportes@quintinhaabc.org` ⏳
- **O quê:** Único email em falta na infraestrutura
- **Como:** Admin Console do Google Workspace → criar utilizador
- **Quem:** Quem tem acesso ao Admin Console
- **Quando:** Esta semana

### T8 — Configurar filtros Gmail no email geral ⏳
- **O quê:** Filtros automáticos para reencaminhar emails da inbox geral para os emails dedicados de cada área
- **Como:** Gmail → Definições → Filtros (lista de filtros prontos a copiar — a preparar)
- **Quem:** Marta ou Inês
- **Quando:** Esta semana (~30 min)

### T9 — Ligar emails dedicados aos canais Slack ⏳
- **O quê:** Cada email de área reencaminha também para o canal Slack correspondente (via email-to-channel do Slack)
- **Como:** Slack → canal → Integrations → "Send emails to this channel" → copiar endereço → adicionar ao reencaminhamento do Gmail
- **Quem:** Marta
- **Quando:** Esta semana
